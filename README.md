# DragScripting
DragScripting - pseudo-framework, which transforms block code to luau.
Author - Kotost.

## Rules
1. You can't setup loop in loops.
2. You can't put any booleans in wait blocks or loops.
3. Loop blocks going from his index to down as many times as you specified in block_count.
4. For convenience, run the script and wait for it to finish, although you can also launch two threads simultaneously.
